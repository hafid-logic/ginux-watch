# team/worker-prompt.md — one-line start prompt for any worker on any platform

Read team/PROTOCOL.md and team/context/worker-pack.md, then pick the highest-priority card in team/tasks/open/ that matches your role, claim it (git mv to team/tasks/claimed/, set claim_until = UTC now+25 min, commit+push; on non-fast-forward rejection pick another card), do the work within its budget, then immediately git mv the card to team/tasks/done/ and push team/results/<T-id>/ (status: done, or partial with what you completed).
