# METHODOLOGY — المنهجية المعتمدة (توجيه v3.3، 2026-11-05)

خلاصة المعتمَد فقط؛ الخلفية التاريخية في docs/methodology-v1.md.

1. **سلّم الأدلة (evidence ladder):** hypothesis ← confirmed (اختبار يفشل بدون الإصلاح وينجح معه) ← branch ← draft-PR (في fork) ← published ← merged. فئة إضافية: **observed-not-host-testable** (تبقى سؤالًا لا PR، ولا تُرقّى في السلّم).
2. **قواعد النشر:** لا نعلن عملًا لم يُبنَ. لا نشر بنص غير معتمد حرفيًا من المستخدم. لا مسودة «ملاحظة فجوة» (gap note) بلا بناء.
3. **سقف الطلبات:** حد أقصى طلبان مفتوحان إلى upstream حتى يُدمج الأول؛ والرد على أي مراجعة (review) في الجلسة نفسها (≤ 24 ساعة). **(تحديث v5.1 في 2026-11-06 بقرار Abdelhafid: للمساهمات العلنية سقف POLICY tier-2b = PR مفتوح واحد — ولا سقف يومي/أسبوعي؛ بقي التزام الرد ≤ 24 ساعة.)**
4. **بوابة الاستبعاد (exclusion gate) قبل أي PR:** dump محدّث (مفتوح/مغلق/مدموج) + PRs وكيل المشرف (HDAE) المفتوحة + مصفوفتنا (matrix). التكرار = إسقاط موثّق.
5. **هوية الـ commits:** توقيع `-s` وهوية «Abdelhafid DJIDEL» + بريد noreply (عبر scripts/session-init.sh). إفصاح الذكاء الاصطناعي في وصف الـ PR.
6. **الأمني:** لا نشر علني أبدًا؛ findings أمنية إلى reports/private/ ثم قرار المستخدم (لا SECURITY.md في upstream).
7. **rebase:** يُطبَّق فقط حين يوجد PR لنا مفتوح (آليًا عند commit يمس ملفاته)؛ لا مزامنة روتينية بلا حاجة.
8. **حدود الميزة التنافسية:** ما ليس ميزتنا: سرعة الإصلاح (وكيل المشرف أسرع). ميزتنا: تحقق مستقل، أدوات لا تنتجها أتمتته، أسئلة مؤيدة بدليل.
9. **الأعمال الثقيلة** (llvm-cov، cargo-mutants، clippy على upstream، fuzz): في GitHub Actions فقط (dispatch + gh run watch)، لا محليًا.
10. **قاعدة الجلسة (توجيه v6.0، 2026-11-06):** عند بداية كل جلسة: اجلب origin وتحقق أن HEAD المحلي = origin قبل أي دمج. الاستثناء المتوقع الموثَّق: المحلي سلف البعيد بسلمات تسليم غير مدفوعة؛ أي تباعد أو تراجع (حادثة إعادة تدوير الصندوق — جلسة 43) = توقف فوري وتحقيق من origin قبل أي كتابة.

أرشيف: docs/methodology-v1.md يبقى مرجعًا تاريخيًا؛ هذه الصفحة هي المعتمد الوحيد.
