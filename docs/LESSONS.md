# LESSONS — ما ينتقل إلى أي مشروع قادم (≤ صفحة، توجيه v3.6 §1b)

1. **سلّم الأدلة إلزامي**: hypothesis ← confirmed ← branch ← draft-PR ← published ← merged، وفئة observed-not-host-testable لما لا يُقاس مضيفًا. حقل `status` في كل بطاقة ومصفوفة. لا قفز بين الدرجات بلا دليل مقيس (MEASURED/OBSERVED/INFERRED/UNVERIFIED على كل رقم).
2. **بوابة الاستبعاد قبل أي مسودة**: dump محدّث (مفتوح/مغلق/مدموج) + مصفوفة التقاطع + PRs وكيل المشرف الآلي؛ التكرار = إسقاط موثق «أُسقط لأنه مطروح» لا مسودة جديدة. أنقذتنا مرارًا (Opp-1، #49/#73).
3. **لا نعلن عملًا لم يُبنَ**: أي «I will work on X» ممنوعة ما لم يكن X مبنيًا وحاضرًا للإحالة. وُلدت من إرجاء مسودة #37 وأصبحت قاعدة دائمة.
4. **تفضيل الأسئلة المؤيدة بدليل على الادعاءات**: أثر بياناتنا (فقرات قياس، إصدارات، SHAs) في قبول سريع أعلى من أي صياغة. النشر حرفيًا بنص معتمد من المستخدم فقط، بسقف (1/يوم، 3/أسبوع). **(تحديث v5.1 في 2026-11-06 بقرار Abdelhafid: السقف الزمني أُلغي ولا يُعاد إدخاله — الحد الوحيد سلامة الخط.)**
5. **تحقق حي عبر API لا فرع محلي**: HANDOFF/STATE ادعاءات والـAPI هو الحقيقة (قاعدة live-state). الدرس الأغلى: حكم «DROP» من تلويث ذاتي — عامل قرأ شجرة فرعنا المحلية ظنًا أنها main (T-20261105-02). أعد التحقق الحي قبل كل اعتماد وقلم المغلقات في الجولة نفسها.
6. **لا بناء ثقيل محليًا — Actions فقط** (fuzz، mutants، coverage، QEMU): صندوقنا يُعاد تدويره ويقتل العمليات الطويلة (6.53M execs أُهملت في استدعاء واحد ملغى). المحلي: تحرير، grep، سكربتات صغيرة.
7. **دروس البيئة**: دوران الصندوق يمحو كل ما لم يُدفع — ادفع بعد كل مرحلة؛ الهوية الافتراضية «Z User» تكتب commits مشوهة — session-init.sh قبل كل commit؛ rustc غير مثبت؛ القرص يمتلئ — الأبنية في Actions والقابل لإعادة البناء يُحذف؛ بعد الدوران `pull --rebase` قبل أي commit.
8. **ما يميزنا أمام مشرف آلي سريع**: ليس السرعة (دمجه الوسيط 0.1–0.2 يوم). ميزتنا: تحقق مستقل متعدد البيئات (host/QEMU/Actions)، أدوات لا ينتجها (fuzz تفاضلي، cargo-mutants، بروفايل أسلوب آلي، مقاييس ذاتية)، وأسئلة مؤيدة بدليل. كرر هذه الأدوات في المشروع القادم ولا تنافس على زمن الإصلاح.
9. **الناقد المستقل يصطاد حقائق وأرقامًا** (6/7 من رفضاته factual/number، صفر style): أطعمه أرقامًا قابلة لإعادة الحساب واقتباسات حرفية، وسيصطاد أخطاءك قبل المستخدم.
10. **الحالة تعيش في git لا في ذاكرة الوكيل**: HANDOFF ≤1200 كلمة كمرجع وحيد، نتائج فورية لكل بطاقة، cron مهمة وليس ضمانة (يموت بالدوران) — Actions هي الخطة الاحتياطية الوحيدة.
